# 差一點地圖（Demo）

市民回報「差點出事」的路口，其他人可以按「我也遇過」。地圖把市民的經驗和**真實事故資料**放在一起看，找出還沒出事、但大家都覺得危險的地方。

本 Demo 為 2026「為桃園做研究」創新點子組提案的原型，範圍是**中壢火車站周邊**。

## 哪些是真的、哪些是示意

| 內容 | 性質 | 來源 |
|---|---|---|
| 每個路口的事故件數（2019–2025）、死亡事故數 | **真實資料** | 桃園市政府開放資料「桃園市A1及A2類道路交通事故」（[data.gov.tw/dataset/46364](https://data.gov.tw/dataset/46364)） |
| 道路、鐵路、車站 | **真實資料** | © OpenStreetMap contributors（ODbL） |
| 市民回報人數、留言、AI 摘要、處理進度、權責單位、修繕紀錄 | **示意資料** | `data-prep/prepare.py` 以固定亂數種子產生，非真實市民回報 |

網頁上每個區塊都有「真實」或「示意」標籤。

## 功能

- **主地圖**：圓圈裡的數字是「也遇過」的人數，顏色深淺代表關心程度（很多人關心／有人關心／回報還少）；綠色勾勾＝多數人說變好了。只呈現「多少人在意」，不幫路口下「危險」或「安全」的判斷
- **三種圖層**：市民回報／真實事故／兩者對照（優先改善、提早預防、可能的盲點、相對安全）
- **三條送市府的路徑**：全區排行（每月前 6 名）、各區排行（每個行政區前 2 名，人少的區也有名額）、快速通道（回報少但嚴重，例如曾經擦撞並附照片、發生過死亡事故）
- **各區關心排行**：中壢區、平鎮區各自一份排行榜
- **路口小檔案**：共鳴人數與組成、AI 摘要、24 小時分布、主要問題、真實事故趨勢、處理進度、誰管這裡、市民的稱讚與抱怨
- **回報流程模擬**：選小角色 → 選路口 →「這裡已有 N 人說過」→ 點選狀況、時段、危險程度 →「你是第 N 位」
- 支援手機版與深色模式

## 在本機執行

需要 Python 3。在 `demo` 資料夾裡：

```bash
python dev_server.py
```

然後用瀏覽器開 <http://localhost:8765>。直接雙擊 `index.html` 打不開，因為瀏覽器不允許用檔案路徑讀取資料檔。

## 從原始資料重新產生

```bash
pip install pandas numpy
python data-prep/fetch_raw.py   # 下載 OpenStreetMap 與事故原始資料到 data-prep/raw/
python data-prep/prepare.py     # 產生 data/ 底下的三個檔案
```

## 方法說明

- **路口**：OpenStreetMap 中兩條不同街道的交會點；同一條路的不同「段」、橋、地名不算；分隔島道路造成的相近交會點（250 公尺內）合併為一個路口
- **事故對應**：事故座標在路口任一交會點 35 公尺內，就算這個路口的事故
- **事故多**：近三年（2023–2025）事故件數在本區路口的前 20%
- **回報多**：回報人數在本區路口的前 30%（和「事故多」一樣用排名，不用固定人數）
- **關心程度**：前 30%＝很多人關心；前 65%＝有人關心；其餘＝回報還少（資訊不足，不代表安全）
- **送市府**：全區前 6 名＋各區前 2 名＋快速通道；很多人關心但名額已滿的，標示「下個月優先」
- **行政區**：路口附近事故資料登記的行政區（這一區有中壢區 23 個、平鎮區 6 個路口）
- **只做路口、不做路段**：本區近三年只有約 30% 事故在路口 35 公尺內，正式版應包含路段

## 檔案結構

```
index.html           網頁
css/style.css        樣式
js/svg.js            圖示、小角色、圖表
js/app.js            地圖、圖層、小檔案、回報流程
data/                網頁用資料（由 prepare.py 產生）
data-prep/           下載與處理資料的程式（raw/ 不進版本控制）
checks/              自動檢查
```
